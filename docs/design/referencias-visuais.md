# Referências Visuais

## Objetivo

Este documento reúne referências visuais utilizadas como base para o design do sistema.

As referências devem ser usadas como inspiração de:

- composição;
- hierarquia visual;
- espaçamento;
- tipografia;
- uso de cores;
- microinterações;
- motion;
- organização de dashboards;
- sensação de fluidez.

Não devem ser utilizadas como cópia direta de layout ou identidade.

---

## Referências principais

### Cuberto
https://cuberto.com/

Usar como referência para:

- animações;
- transições;
- microinterações;
- sensação premium;
- movimento suave;
- respostas visuais a hover e clique;
- personalidade visual.

Não usar como referência para:

- excesso de efeitos;
- animações pesadas;
- 3D contínuo em telas operacionais.

---

### Copilot Money
https://www.copilot.money/

- dashboards financeiros;
- cards;
- hierarquia de números;
- organização de informações;
- gráficos;
- visual minimalista;
- experiência mobile;
- interface escura.

## Direção visual consolidada

A identidade do sistema deve combinar:

- Copilot Money para organização e leitura financeira;
- Cuberto para movimento e personalidade;
- Apple para minimalismo;
- Ramp e Rho para seriedade empresarial;
- Active Theory e Lusion para inspiração de motion.

Objetivo final:

> Uma interface escura, minimalista, premium, rápida, responsiva e agradável de usar.

---

## Princípios

1. Nenhuma animação deve atrasar uma ação.
2. O sistema deve parecer rápido mesmo durante carregamentos.
3. O conteúdo financeiro deve ter prioridade visual.
4. O uso de cor deve ser semântico.
5. Evitar poluição visual.
6. Priorizar mobile-first.
7. Toda interação deve funcionar bem também em desktop.

Princípio principal:

> Motion must never delay work.
